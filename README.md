## Getting Started

To set up the project locally, you need to have this calculator : Casio Graph Math+. To get a local copy up and running follow these steps.

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/lock94656/snake.git
   ```
2. Upload the code in to your Casio.
3. Run it.
<p align="right">(<a href="#readme-top">back to top</a>)</p>


<!-- USAGE EXAMPLES -->
## Rules of the game

The goal is to bite all the apples who appear randomly before dying. If you touch the border of the screen you lose one live (You have 3 lives)

To move the snake, you must press the arrow keys on the calculator.

## Usage

To launch the program, go to the python app on your calculator, open the program, press the "Tools" button and choose "Execute".
